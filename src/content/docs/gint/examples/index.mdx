This section collects gint examples for the ClassPad. These are not only beginner demos: some examples show lower-level hardware and profiling techniques.

Some examples are adapted from `Lephenixnoir/gintctl` on the Planet Casio git forge. The original program targets several calculators, so the wiki versions are simplified for ClassPad and avoid keys that do not exist on this port. If you need help finding projects on the Planet Casio forge, see the [forge migration post](https://www.planet-casio.com/Fr/forums/topic17716-1-migration-de-la-forge-gitea-en-forgejo.html).

## gintctl examples

- [Render timing](/wiki/gint/examples/gintctl/render-timing/) - Measure drawing and display update time.
- [Register browser](/wiki/gint/examples/gintctl/register-browser/) - Read hardware registers directly.
- [Memory peek](/wiki/gint/examples/gintctl/memory-peek/) - Read raw memory with exception guards.

## Templates

For a full starting project, use [gint-template](https://github.com/TheRainbowPhoenix/gint-template). If you want a touch-friendly UI example, use the [Gint + JustUI template](https://github.com/TheRainbowPhoenix/USB_test).
