:::note[ClassPad keys]
This page lists the key codes known to work on the ClassPad port. Avoid using keys from other gint targets, like function keys, unless you have tested them on ClassPad.
:::

## Confirmed keys

```c
enum
{
  KEY_SHIFT  = 0x81,

  KEY_LEFT   = 0x85,
  KEY_UP     = 0x86,
  KEY_EXIT   = 0x74,
  KEY_DOWN   = 0x75,
  KEY_RIGHT  = 0x76,

  KEY_7      = 0x41,
  KEY_8      = 0x42,
  KEY_9      = 0x43,
  KEY_DEL    = 0x44,

  KEY_4      = 0x31,
  KEY_5      = 0x32,
  KEY_6      = 0x33,
  KEY_MUL    = 0x34,
  KEY_DIV    = 0x35,

  KEY_1      = 0x21,
  KEY_2      = 0x22,
  KEY_3      = 0x23,
  KEY_ADD    = 0x24,
  KEY_SUB    = 0x25,

  KEY_0      = 0x11,
  KEY_DOT    = 0x12,
  KEY_EXP    = 0x13,
  KEY_NEG    = 0x14,
  KEY_EXE    = 0x15,

  KEY_FRAC   = 0x51,
  KEY_FD     = 0x52,
  KEY_LEFTP  = 0x53,
  KEY_RIGHTP = 0x54,
  KEY_COMMA  = 0x55,
  KEY_ARROW  = 0x56,

  KEY_KBD    = 0xa1,
  KEY_X      = 0xa2,
  KEY_Y      = 0xa3,
  KEY_Z      = 0xa4,
  KEY_EQUALS = 0xa5,

  KEY_CLEAR  = KEY_EXIT,
};
```

## Common choices

Use `KEY_EXE` for confirmation or opening a menu.

Use `KEY_EXIT` or `KEY_CLEAR` to leave a screen. On ClassPad, `KEY_CLEAR` is an alias for `KEY_EXIT`.

Use the arrow keys for movement and list navigation.

## Example

```c
clearevents();

if (keydown(KEY_EXE)) {
  // Confirm or open menu
}

if (keydown(KEY_EXIT)) {
  // Leave the current screen
}
```
