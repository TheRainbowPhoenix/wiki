This is the API reference for the **gint kernel headers**, generated from the gint source for the ClassPad port (target **fxCP**, the fx-CP400). Pages are generated directly from the headers with preprocessor conditions resolved for the ClassPad, so only APIs that exist on this platform are listed.

Hardware that only exists on other models is not covered here (fx-9860G and fx-CG 50 only: `display-fx`, `gray`, the `t6k11` and `r61524` drivers). Those headers are excluded from generation.
