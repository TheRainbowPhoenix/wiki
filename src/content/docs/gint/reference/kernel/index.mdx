This is the API reference for the **gint kernel headers**. The ClassPad port of gint targets **fxCP** (the fx-CP400). Some pages document hardware that only exists on other models (fx-9860G and fx-CG 50 only: `display-fx`, `gray`, `t6k11`, `r61524`). Those pages are included for completeness and do not fully apply to the ClassPad.
