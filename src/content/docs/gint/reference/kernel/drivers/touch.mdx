## Functions

### `touch_scan`

Run a scanning round and return the next event. This function is not
reentrant and is already called by the input timer. Don't call it!

```c
key_event_t touch_scan(void)
```

---

### `touch_get_last_scan`

Get the last captured data from any of the 3 stages. All pointers can be
NULL; fills the structures that are provided.

```c
void touch_get_last_scan(struct _touch_adraw *raw, struct _touch_adconv *conv, struct _touch_addots *dots)
```

## Data structures

```c
struct _touch_adraw { /* Response to command 0x84 */ u16 x1, y1, z1, gh; u16 x2, y2, z2, dm; /* Whether data is present (if false, everything is 0 and no touches) */ bool has_data; }
```

Second stage: decoded form of command 0x84 output.

```c
struct _touch_adconv { /* Number of touches (0, 1 or 2) */ int touches; int x1, y1; int x2, y2; int z1, z2; u16 gh, dm; }
```

Third stage: screen-space dots information.

```c
struct _touch_addots { /* Number of touches (0, 1 or 2) */ int touches; /* Valid if touches >= 1 */ int x1, y1, z1; /* Valid if touches >= 2 */ int x2, y2, z2; }
```
