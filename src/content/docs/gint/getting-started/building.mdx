This guide will walk you through building a gint application for the ClassPad. While we finish writing it, here are the **quick facts**:

- Build with **`fxsdk build-cp`** from a gint template project.
- Or use the template's **devcontainer / Docker image** (`ghcr.io/therainbowphoenix/gint-docker`) so there is nothing to install or configure manually.
- The output is an **`.hh3` file**: copy it to the **root of the calculator** and launch it from the **Hollyhock launcher**.

That's really all there is to a first build — the detailed guide with screenshots, toolchain installation and troubleshooting is on its way.
